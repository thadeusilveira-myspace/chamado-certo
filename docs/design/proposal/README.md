# Proposta de Nova Identidade Visual — MamiFIT

Proposta de redesign de front-end ("nova cara") do app MamiFIT, elaborada pelo squad
de front-end **Nirvana** a partir das telas atuais. Material para apresentação aos
**donos do aplicativo** — é proposta de design, não implementação.

## Como ler

1. **[`00-PROPOSTA-NOVA-IDENTIDADE.md`](./00-PROPOSTA-NOVA-IDENTIDADE.md)** — documento executivo principal: resumo, diagnóstico, comparação das 3 direções, **recomendação**, sistema de design, redesenho tela a tela e roadmap. **Comece por aqui.**
2. **[`01-brief-auditoria.md`](./01-brief-auditoria.md)** — auditoria visual detalhada do app atual (paleta, tipografia, componentes, problemas).
3. **[`direcoes/`](./direcoes/)** — as três direções visuais na íntegra:
   - [`direcao-A-serenidade.md`](./direcoes/direcao-A-serenidade.md) — Calma & Premium
   - [`direcao-B-conquista.md`](./direcoes/direcao-B-conquista.md) — Vibrante & Gamificada ⭐ *recomendada*
   - [`direcao-C-clareza.md`](./direcoes/direcao-C-clareza.md) — Editorial & Clean

As capturas das telas atuais usadas como base estão em [`../screens/`](../screens/).

## Recomendação em uma linha

**Direção B — "Vibrante & Gamificada (Conquista)"**, dark-first, preservando o roxo e
a gamificação que as usuárias já reconhecem, refinada com a disciplina de contraste (AA)
e o respiro editorial das outras duas direções.
